# Proyecto que modifica el código del juego snake.py para hacerlo más interesante
Este juego clásico se trata de un vibora que va comiendo fruta y creaciendo, pero pierdes si chocas con un pared o contra ella misma.

Se modifico el código para que la fruta se moviera un paso a la vez de forma aleatoria, complicando el que la vibora coma.
Además se agrego una lista de colores que te puede salir tanto la víbora como la fruta de forma aleatoria.

Estos cambios se realizaron con el fin de aumentarle la dificultad al juego y darle más personalidad.
